# Changelog

## v1.0.0 (2026-06-17)

### Features

- ✅ **GUI version** - Easy-to-use graphical interface, no command line needed
- ✅ Batch import Steam friend codes
- ✅ Automatic friend request sending
- ✅ Exclude list support (skip specific friends)
- ✅ Auto-skip users who are already friends
- ✅ Support both friend codes and SteamID64 formats
- ✅ Auto-delay between requests to avoid Steam rate limits
- ✅ Real-time log output
- ✅ **One-click EXE packaging** via `build.bat`
- ✅ Command-line version for advanced users
- ✅ GitHub Actions automated release builds
